鉴中观象是一款免费、公益、隐私优先的**微信原生小程序**，用于本地查看受支持的相机 RAW、PSD、PSB、TIFF、PDF 兼容 AI 与静态 SVG，并在受支持的格式上保存原尺寸 PNG 或相机内嵌 JPG。文件从微信聊天文件/图片或相册原图选择，RAW可用性以实际返回字节为准；不上传到开发者服务器、不改原稿，无需额外注册账号。AI 中保留微信原生 PDF 查看与主动转发 PDF 副本；不接收独立 PDF 文件，也不提供 AI 转 PNG。PNG 文件分享仍不提供。没有后端、独立 PDF 阅读器或 Android/iOS App 工程。

界面提供青墨、宣纸、夜墨三种主题，本地保存偏好；格式卡片、缩放控件和主题浮层使用新拟态同色表面、明暗双影，按下及主题选中时使用内凹双影。首页选文件、打开/分享 PDF、保存原尺寸图片等主要按钮统一复用主题强调色、轻微凸面渐变与外阴影，按下呈内凹反馈，主按钮点击高度至少44px；返回、缩放等辅助操作保留同色表面并统一内凹按压反馈；首页文件标识使用强调色底、薄荷折角与细线条。复用主题变量，保留原有布局、文字对比、点击区域和安全区；本轮新样式尚待微信实际显示验证。既有主题浮层展开采用160–180ms淡入与轻微上移，切换配色采用180ms过渡，不改变设计稿或导出颜色。双边均不超过32 px的极小PSD/PSB使用最近邻色块预览，普通设计稿保持平滑缩放；此调整仅影响显示。

首页格式卡片下方（SVG行之后、详细说明之前）将隐私说明与反馈入口集中展示：隐私说明分两行居中，使用主题浅色文字、不带绿点，保留“本机解析、不修改原稿”和“AI中的PDF由用户主动转发”的完整含义；其下提供居中文字入口“反馈建议 ↗”，文字使用`var(--control)`；无胶囊背景或边框，点击区域至少44px高。可点击部分保留微信原生反馈行为（`open-type="feedback"`）。首页恢复原有宽松留白、字号、区块间距和完整说明，保留底部安全区；短屏自然滚动，不压缩为单屏。独立普通PDF入口继续移除。反馈关联当前小程序，由管理员登录微信小程序管理后台查看，无需绑定个人邮箱或个人微信聊天。用户主动提交的反馈内容由微信处理，小程序不会自动附带设计原稿；未引入反馈SDK、自建表单或后端。本轮仅完成入口接入，微信开发者工具及Android/iOS实际提交反馈均为NOT_RUN。

本公开仓库用于提供经审查的源码快照；原私有开发仓库及其 Git 历史不属于公开范围。未经授权的设计原稿、参考图、设备截图和本地私人测试产物不随公开源码分发。APK 是否通过 Releases 发布，仍需单独确认。

保留既有随主题变化的 WXSS 加载动效、180ms 高清防抖、完整可见区域覆盖、缩放和返回取消。初始解析、高清和高质量 PNG 生成串行使用 Canvas，过期结果不覆盖新文件；后台取消高清、前台重新安排。保存图片时显示中央状态层。原尺寸流式生成按实际行数更新进度，相册保存期间显示等待状态。历史 Android 概览、局部和平移结果仍按已测范围记为 **PARTIAL_PASS**；后续原尺寸回传核对结果见下文。

## 构建与打开

需要 Node.js 22.22+（本机实际使用 24.22.1）和 pnpm 11.25.0。依赖版本及完整性锁定在 `pnpm-lock.yaml`。

P1 维护更新将 pnpm 固定为 11.25.0；GitHub Actions 使用 Node.js 24.22.3，按安装锁定依赖、类型检查、构建、测试的顺序执行。构建在测试之前生成平台用例需要的 `dist/`。本地检查通过与 GitHub Actions 实际运行、微信真机验收分别记录。

本轮增加内存告警后的概览回退、导出期间防息屏与前台提示、首页空闲时的新版本提醒。更新确认会重新检查文件和任务状态；正在查看、选择、生成或关闭任务时不会重启。失败提示补充实际 Photoshop 模式、位深、通道和已读取到的压缩方式，并给出 PNG/JPG 替代方式。

P2 预览交互增加双击循环：适应屏幕 → 2 倍 → 可用的原像素检查倍率 → 适应屏幕。第三档只复用当前有效高清局部解码器，超出既有缩放范围时跳过；相机 JPEG、普通图片或 SVG 无此解码器时在适屏与 2 倍间切换。拖动、多指缩放、长按、取消与过期视口查询不会作为双击继续处理。页面启用自动横竖屏与可调整窗口，沿用实际视口坐标刷新；极小 PSD/PSB 的显示 Canvas 在尺寸变化时重新适配，导出图片不变。本轮微信原生手势、系统方向锁和旋转行为仍需真机验证。

预览框按主图实际比例收紧，缩放条保持“− / 百分比 / ＋”完整；宽高比不同于屏幕时保留完整画面，框外使用主题背景，原画布的透明区域不裁掉。主保存按钮保持在屏幕底部安全区，手势说明置于图片外，不遮挡画面；说明区利用图片下方剩余高度，长说明可滚动，边框只包住实际内容。工具中可切换棋盘、白、黑背景，仅改变显示。文件详情复用已读元数据，区分概览 PNG、相机 JPG 和传感器有效画面；未读取的 DPI、ICC 名称与图层数如实标注。支持的微信通过原生返回层将预览中的系统返回接到首页；上滑回桌面与任务切换仍由系统处理，这条手势路径待真机复测。

## 实际支持范围

**已验证的指定 PSD 样本包括 107.25 MiB RGB8 RLE 和 613.23 MiB RGB16 Raw；32 MiB 是完整解码预算，并非大图预览的统一文件上限。** 107.25 MiB 样本为112,459,862字节、19056×15276、RGB8/3通道；其历史概览与局部高清有开发者工具证据，Android 有历史概览/放大证据。613.23 MiB 样本有 Node 实际文件验证和历史 Android 局部/平移截图。两份指定样本的安卓原尺寸导出回传另经字节核对，仍不代表任意大 PSD/PSB 兼容、新自动保存流程或 AI 新路径已完成手机验收。

受控支持 **PSD v1 RGB16 RAW**：真实643,022,736字节（613.23 MiB）、6016×4016、5通道样本已完成Node实际读取、颜色与适配验证。完整可见区域按原图坐标读取，输出单边≤1365px；两个额外通道不作Alpha。16行批量和单次512 KiB上限保持。Android旧概览、不同局部及平移为PARTIAL_PASS；该人像原尺寸PNG回传与Node输出字节一致。面积预览保存、新自动保存及长期运行仍须独立真机验证，不代表任意600 MiB文件均兼容。

缩放比例以“适应屏幕”为基准，100%不代表原图物理像素1:1。保存入口只交付原尺寸 PNG 或可用的相机内嵌 JPG，显示输出格式和像素尺寸。原尺寸 PNG 优先复用已有扫描行导出。

## V1.1 色彩与高质量预览 PNG

从资源1039有界读取 ICC（最多1 MiB、256个Tag、TRC最多4096点），检查头、长度、偏移、重复Tag和异常重叠，允许标准规定的完全共享TRC。支持当前验证的 RGB/XYZ 矩阵与 `curv` TRC 配置，包含实际 ProPhoto RGB 和 sRGB；不按配置名称猜测颜色。采用源TRC、D50 PCS矩阵、到sRGB的白点适配与传递函数，以相对色度、无黑点补偿转换，超色域分量裁剪。RGB16先保留uint16精度完成转换，最后量化RGBA8；额外通道不作Alpha。数值核实为sRGB时直接旁路，缺失或不支持的配置准确提示未管理，非法配置安全拒绝。LUT、参数曲线及任意ICC通用兼容不在当前范围。[ICC矩阵/TRC与共享Tag规范](https://www.color.org/specifications/ICC.1-2022-05.pdf)

真实人像七个256×256同坐标区域，经当前产品解码路径转换后，对Photoshop sRGB参考PNG的RGB MAE为 **0.00634–0.01439、最大通道差1**；原始未管理MAE为4.75–22.42。sRGB海报七个原像素区域的全部RGBA与旧结果相同。RGB8/已有PSB完整路径及分段路径复用该颜色解释；小文件Alpha保留。结果属于Node实际文件验证，不是Photoshop逐像素等色或真机PASS。

初始概览与高清交互保留快速2×2取样；历史“保存预览 PNG”路径曾复用同一会话按源像素实际交叠面积执行Box平均，再经过同一ICC变换，缓存完整概览PNG供下次保存。不会把局部块或放大的概览冒充原图。海报面积采样读取45,828行、约38.81 MB，Node解码约4.22秒，明显多于快速概览，因此不强加到每次打开和平移。输出仍为人像1365×911、海报1365×1094，尺寸来自实际结果，Canvas上限未提高。

统一几何与sRGB后，用Photoshop参考PNG经LANCZOS缩到相同输出作为对照：人像全图MAE **0.3942→0.2569**，海报全图 **1.7183→0.9913**，海报“项目简介”区域 **5.1643→2.9277**。这证明当前样本混叠降低；不同重采样方法和边缘量化仍有差异，不是无损原尺寸输出或AI增强。

未引入色彩 SDK。预览额外高精度缓冲仅按输出像素分配，最大约21.3 MiB，行前缀/ICC等纳入原96 MiB估算预算；不分配原图RGBA。Node进程采样RSS包含运行器及测试工具，不能作为手机峰值。原尺寸导出采用下面独立的有界扫描行编码路径，不提高预览 Canvas 的尺寸限制。

## JZG-RAW-M0：导入来源与真实图像识别

首页只保留上下两个直接入口，不再弹出来源菜单：主按钮“从微信聊天选择文件”统一使用官方`chooseMessageFile({type:'all'})`；第二行“从相册选择 RAW 图片”直接打开相册原图选择，保留带边框、阴影和单行文字的样式。聊天中的文件、图片及其他分类统一进入同一个选择列表，选后按真实文件头和容器结构筛选受支持的格式，视频或未知内容安全拒绝。两入口都不保证微信返回相机RAW原始字节；实际取得JPEG/PNG时明确标为普通图像，不启用传感器功能。

AI 的 PDF 兼容内容按原字节保留，不压缩、不降采样。2026-11-02只读核对的指定“演讲会桌签.ai”与对应PDF均为2,530,656字节、SHA-256一致，包含矢量图形及嵌入字体。预览清晰度受微信内置查看器影响；已安装官方类型定义中的 `openDocument` 没有DPI、分辨率或高清模式参数（官网本次无法访问），当前不提供画质调节。若预览仍模糊，可主动转发PDF后使用其他阅读器查看原始内容；不将此说明视为微信真机画质已改善。

仅对通过既有兼容检查的 AI，按原字节创建其 PDF 兼容内容的本地副本，调用微信 `openDocument` 查看。独立普通 PDF 不在文件选择或支持范围内。原生查看仍设置 `showMenu:false`；支持 `shareFileMessage` 的环境另提供“分享 PDF 到聊天”按钮，在用户点击时同步调用。该分享API的已安装官方类型标注最低2.16.1，界面按实际能力显示；全应用最低基础库仍为2.11.0，不支持分享时保留预览。打开期间保留副本，返回或换文件后的清理延后到在途操作结束；过期回调不覆盖新文件。

PDF副本可能保留Illustrator编辑数据和元数据，不宣称已清除隐藏信息或重新导出PDF。它是原PDF兼容内容的副本，不是任意AI转换；沙盒副本不等于保存公共下载目录。双页结构控制样本的字节和页数经独立pdf-lib读取验证；当前本地查看器路径继续保留；新增独立分享的Node合约通过，微信双端待测。

### V1.2 AI 真实样本回归

当前素材目录已核实3份真实AI，均为PDF 1.5、单页、未加密，最大2,530,656字节（约2.413 MiB）。原`inspectAi`及独立pdf-lib解析均通过。新路径复用相同兼容判断，分段读取文件头、尾部、xref及Illustrator标识，再使用微信官方`FileSystemManager.copyFile`生成原字节PDF副本，取消时等待在途复制结束后清理，不再把整份AI放入JS ArrayBuffer。

真实样本的Node文件/微信API桩均为 **REAL_FILE_NODE_PASS**：每份5次JS读取、总79,888字节、最大64 KiB，另1次原生复制调用；副本大小及128 KiB分块SHA-256与原稿一致，页数1。历史打开、取消、失效、复制期间清理及当时的分享桩测试记录保留，本轮分享以同步点击调用的实现和当前测试为准；测试副本随后删除，不作为交付附件。原生复制内部的缓冲大小未知，不能把Node调用结果当作真机通过。copyFile不可用时明确提示升级，不编造最低版本。

生产AI保护仍为 **32 MiB**。当前没有真实超32 MiB样本；另生成约36 MiB合法单页PDF结构控制，经独立MuPDF解析无需修复，通过有界只读诊断和生产超限拒绝测试（未启动复制），仅记 **SYNTHETIC_PASS**。这不是“真实大型AI已支持”，也不代表已放宽生产上限。该AI分段校验阶段未修改SVG/PSB或其他V1.1业务逻辑，当时新增AI路径的开发者工具与Android/iOS结果均为 **NOT_RUN**；本轮仅恢复独立主动PDF分享，保留原有文件大小保护。

## AI 的 PDF 兼容内容边界

- 仅接收受支持的 AI，不提供独立普通 PDF 的选择或本地预览。AI 仍须有 PDF 兼容内容及可确认的 Illustrator 标识，保持 32 MiB 上限，先进行有界结构检查，再由官方文件复制接口创建原字节 PDF 副本，不整读 AI 到 JavaScript 缓冲区。
- 点击“分享 PDF 到聊天”时直接调用微信分享接口，不先异步生成、复制或检查文件，避免丢失用户点击手势；取消分享不报错，分享完成前保留副本。原始PDF可能含私有编辑数据与元数据，不代表已脱敏。
- 当前不提供AI转PNG。离线开源渲染试验发现3份私人AI的复杂非隔离透明组无法可靠还原，可能出现严重错色；依照预览工具定位，已撤出该渲染实现、分包、字体和新增依赖，不输出残缺PNG。调查证据仅留在忽略目录，不随代码交付。PNG保存提供受支持的PSD/PSB、TIFF及SVG路径。
- AI 内查看与转发 PDF 的本轮调整尚未在微信开发者工具、Android、iOS 验证，均为 **NOT_RUN**；既有 AI 原生预览的历史实测不视为当前分享通过。自动 GUI 操作仍暂停。

## 文件、内存与临时副本

- PSD/PSB **完整缓冲区路径仍限32 MiB，该值不是所有 PSD 预览的文件上限**；超过完整解码的文件、尺寸或估算预算时进入有界分段预览/缩略图路径，不整读大文件。指定107.25 MiB及613.23 MiB样本分别有分层证据；其他文件仍受模式、通道、压缩方式、行索引与输出预算限制。AI 仍最大 **32 MiB**，SVG 源文件最大 **1 MiB**、安全重建后 **512 KiB**。以实际文件 stat 为准；大 Photoshop 文件先读26字节头，其余情况先读最多4096字节。
- Canvas 与**预览 PNG**保留工程保护上限：单边最多 **1365 px**，不代表原稿尺寸或流式原尺寸 PNG 的上限。大 Photoshop 文件先生成概览，视口稳定后读取原图局部；保存预览不会保存当前高清块。只显示内嵌 JPEG 时禁用 PNG；超限 SVG 可尝试原生预览，PNG 禁用。[官方 Canvas 说明](https://developers.weixin.qq.com/miniprogram/dev/component/canvas.html)
- SVG/完整核心解码上限仍为单边 **4096 px**、总像素 **4,194,304**。SVG 最多10,000节点、32层嵌套。原稿尺寸不作为大文件预览的输出尺寸。
- 原共享预算 **96 MiB** 未提高。完整路径仍使用 `3 × 文件字节 + 宽 × 高 × (通道数 + 20)` 估算；分段路径计入有界输出、高精度 RGB、ICC、面积采样行前缀、行索引和行缓冲。RLE 行表最多 **8 MiB**、压缩行最多 **1 MiB**，表按64 KiB块读取。1036缩略图 JPEG 最多 **2 MiB**，资源目录最多 **4096项**，另校验尺寸、长度及 JPEG 头；1033 BGR 不显示。
- `src/core/photoshop-preview.ts` 对 RGB8/3通道 Raw/RLE 逐行范围读取，概览与降采样局部采用最多2×2分层取样抗锯齿，原像素局部可按1:1读取。行索引复用，每次仅保留两条单通道行缓冲和有界输出，不分配整原图 RGBA；快速路径未采样行不作像素校验。V1.1按受支持ICC处理颜色，保存时面积采样遍历所需RGB行，不重建图层。页面在视口稳定180 ms后加载，最多一个请求和一个显示中的高清块，替换时尝试释放旧块。上述预算不是已测真机内存峰值；渲染Canvas完成后退回1×1。
- [官方 readFile](https://developers.weixin.qq.com/miniprogram/dev/api/file/FileSystemManager.readFile.html) 注有单文件100M限制；本项目的107.25 MiB样本已通过开发者工具分段读取及历史 Android 概览实测，不据此推断所有手机或更大文件均可行，仍须按设备和实际文件验证。
- 本地派生副本仅写入 `wx.env.USER_DATA_PATH/quickview-v1/qv_*.svg/pdf/jpg/png` 和微信 PNG 临时路径；更换文件、返回首页、页面卸载及下一次选择时尝试清理，在途文档/复制/原尺寸写入及相册保存完成后再清理相应副本。用户发起PNG保存后由微信执行相册写入；PDF分享仅由用户点击独立按钮发起，PNG文件分享仍不提供。Canvas 临时文件由微信平台管理；开发者工具中返回后旧 PNG 仍可访问，不能宣称已物理删除。不会删除或改写原始设计文件。
